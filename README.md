# wobまんちゃんのコインラッシュ！

## 起動方法

1. このフォルダーの [index.html](./index.html) をダブルクリックします。
2. 初回はユーザー名を2〜12文字で入力し、「名前を保存」を押します。次回からは保存した名前が自動入力されます。
3. ステージを選び、「ゲームスタート」をクリックします。
4. PCは矢印キー（↑ ↓ ← →）、スマホはゲームフィールド内のドラッグでwobまんちゃんを動かします。

Edge、Chrome、Firefoxなどのブラウザで動きます。インストール、インターネット接続、サーバーの起動は不要です。ファイルを修正した後はブラウザで再読み込みしてください。
開かない場合は、[index.html](./index.html) を右クリックし、「プログラムから開く」でブラウザを選びます。

## コイン

| 種類 | 得点・効果 | 出現率 |
| --- | --- | --- |
| 金色の通常コイン | 1ポイント | 70% |
| 青コイン | 2ポイント | 15% |
| 虹色コイン | 3ポイント | 8% |
| 緑色のスピードアップコイン | 得点なし・5秒間、通常速度の1.5倍 | 7% |

出現率は1枚ごとの確率です。毎回同じ割合の枚数になるわけではありません。
最大8枚がフィールドに出現し、取得後はランダムな場所に補充されます。スタート地点から到達できる場所だけを候補にし、柵の内部・柵と重なる位置・池の中には出現しません。

## ステージ

| ステージ | 内容 |
| --- | --- |
| 1. 草原 | 障害物なし |
| 2. 公園 | 通り抜けできない柵と花壇 |
| 3. 散歩道 | 入ると減速する池 |
| 4. 広場 | 柵と池が混在 |

全ステージ60秒制です。ステージを変更すると、その時点のプレイを終了し、スコア・残り時間・効果をリセットしてスタート待ちになります。

### 移動速度のルール

- 池に入った瞬間から **2秒間、通常速度の50%** になります。
- 池の中に居続けても減速を延長しません。池から出て入り直すと、新たに2秒間減速します。
- 加速と減速の両方が有効な間は **1.5 × 0.5 = 通常速度の0.75倍** になります。
- それぞれの効果が終了すると残っている効果だけが適用され、両方終了すると通常速度へ戻ります。
- 加速コインを続けて取った場合は、加速の残り時間を5秒に更新します。倍率は1.5倍のままです。
- 斜め移動でも直進と同じ速さです。

## 時間・記録・リスタート

- 60秒で操作を終了し、そのステージの獲得スコアを表示します。
- 別のタブを開いている間も制限時間と速度効果の時間は進みます。
- 「もう一度あそぶ」または「リスタート」で同じステージを最初から遊べます。
- 最高記録は各ゲーム終了時にブラウザのlocalStorageへステージ別に保存します。Ver.1の記録がある場合は、草原の記録として引き継ぎます。
- 保存禁止設定でも遊べますが、その場合はページを閉じると記録が失われます。
- 別のブラウザやフォルダーへの移動後は、以前の記録が表示されない場合があります。

## BGM・効果音

Web Audio APIの発振器で作ったオリジナル音源です。外部の音声ファイルは使用していません。

- 明るいループBGM
- 通常コイン、青・虹コイン、スピードアップコインの取得音
- 池への進入音
- タイムアップ音

「BGM ON/OFF」と「効果音 ON/OFF」を個別に切り替えられます。ゲーム開始ボタンを押した後から音が鳴ります。開始前は鳴りません。別のタブに移ると音を止め、プレイ中に戻るとBGMを再開します。
音が聞こえない場合は、ブラウザやPCがミュートになっていないか確認し、音のスイッチをOFF→ONにしてください。Web Audio APIに対応しないブラウザでも、ゲーム自体は音なしで遊べます。

## キャラクター画像の配置

使用するファイルは [assets/wobman.png](./assets/wobman.png) です。フォルダー直下にあった提供画像を、内容を変更せずここにコピーしました。元のファイルも残しています。

画像を差し替えるときは、このファイルを同名のPNGに置き換え、ブラウザを再読み込みします。縦横比を保ち、最大76×76の枠に収めて描画します。透明背景のPNGを推奨します。読み込みに失敗した場合は配置案内を表示し、別キャラクターには置き換えません。

## 正式名称・ユーザー名・ランキング・スマホ対応の更新

正式名称を「wobまんちゃんのコインラッシュ！」に統一しました。タイトル、ブラウザのタブ、スタート画面、結果画面、ランキング画面、説明書に反映しています。日本語の区切りで2段にし、軽い登場アニメーションと星の装飾を追加しました。「動きを減らす」設定にも対応しています。

### ユーザー名とプレイヤー切り替え

- 初回は2〜12文字のユーザー名を登録します。前後の空白を除き、日本語や絵文字も入力できます。
- 名前はブラウザに保存され、次回起動時に自動入力されます。
- 画面の「プレイヤー」を開くと、名前の変更・プレイヤーの新規作成・切り替えができます。
- 名前変更では同じプレイヤーIDを維持するため、自己ベストは消えません。別の人が遊ぶ場合は「新規」を使ってください。同じ名前を重複登録することはできません。
- 名前やランキングはHTMLとして挿入せず、文字列として表示します。
- ゲーム中は名前の編集を止め、開始時のプレイヤーに結果を記録します。

### この端末のランキング

- ステージごとにTOP30を表示します。各プレイヤーの自己ベスト1件のみを掲載します。
- 同点は、そのスコアを先に記録したプレイヤーが上位です。同点で再プレイしても先着順は変わりません。自己ベストを更新したときだけ新しい記録順になります。
- 終了後の「ランキングを見る」から確認でき、ランキング内でステージを切り替えられます。
- 31位以下の自己ベストも内部には残し、次の更新時に上位へ入れるようにしています。
- この端末・このブラウザの記録です。全国共通のランキングではありません。
- 過去の最高記録には誰の記録か分からないため、既存の「端末ベスト」として維持し、新しいプレイヤーへ勝手に割り当てません。

保存キーは既存の `coin-hop-best-v1` と `coin-hop-best-v2` を維持しています。名前・プレイヤーID・新ランキングには、新しい `coin-hop-ranking-v1` を追加しました。名称変更による既存キーの削除・改名はしていません。
保存できない環境では案内を表示し、そのページを開いている間だけ名前とランキングを保持します。

### スマートフォン

- スマホの操作は仮想ジョイスティックです。フィールド内に指を置き、行きたい方向へ少しドラッグすると、その方向へ移動し続けます。指の方向を変えると進行方向も変わり、離すと止まります。矢印ボタンは表示しません。
- スマホ縦画面は594×800、PCは従来の960×540のフィールドを使います。スコア・時間・ステージ選択・サウンド設定を上部へまとめ、フィールドを画面の中心に置きます。
- ゲームフィールド上での意図しないスクロール、文字選択、長押しメニューを防ぎます。通常の設定やステージ選択は操作できます。
- 音声は開始操作で有効化します。中断された音声は、フィールドの次のタッチで再開を試みます。
- スマホからPC上のローカルファイルへ直接アクセスすることはできません。スマホ実機で遊ぶ場合は、ファイル一式をHTTP/HTTPSで配信できる環境へ置く必要があります。現在は外部への公開・アップロードを行っていません。

## スマホUIと操作の改善

- 開始・終了モーダルの幅はフィールド内に収め、高さが足りない場合はモーダル内部を指でスクロールできます。小さい画面でも開始ボタンに移動できます。
- ページの最小幅320pxという制限を取り除き、スクロールバーを除いた表示幅に合わせて設定欄やスコア欄も縮めます。
- 縦長フィールドでは、柵・池・移動範囲・コイン生成・到達可能な経路も594×800の座標へ対応しています。キャラクター画像とコインを縦長に引き伸ばす処理ではありません。
- ドラッグを始めた場所がジョイスティックの中心になります。そこから10ピクセル以内は動かず、それを超えると任意の方向へ一定の速さで移動します。
- 中心へ指を戻しても止まります。2本目の指で入力を奪わないようにし、指を離す・タッチがキャンセルされる・画面を切り替える・向きを変えると入力を解除します。
- 画面の向きを変えても、スコア・制限時間・加速／減速の終了時刻を保持します。障害物配置を切り替え、コインを新しい座標の安全な場所へ再配置します。
- PCの横長フィールド、矢印キー、画像、音声、ユーザー名とランキングの保存キーを維持しています。

縦長フィールドと入力の29件の検証は [tests/mobile.html](./tests/mobile.html) をダブルクリックして再実行できます。既存ルール30件、ランキング17件と合わせて76件の成功を確認しています。画面サイズとタッチ操作の確認方法・未検証事項は [VALIDATION.md](./VALIDATION.md) を参照してください。

## スマホのサイズバランス調整

- フィールドの論理横幅を540から594へ10％拡大しました。左右の余白を減らし、実表示も幅360・390・430pxの環境で約7〜9％広くしています。小さい画面では幅と高さの両方へ収まる大きさを優先します。
- キャラクターとコインは描画寸法を1.2倍にし、衝突半径・取得範囲・生成間隔も同じ設定に連動させています。PNGの縦横比と移動時の弾みを維持します。
- 柵の囲い全体と池の半径を0.85倍にしました。柵の四隅はつながったまま、描画と当たり判定に同じ矩形を使います。池の水面と減速判定にも同じ楕円を使います。
- 拡大したキャラクターが画面端で欠けないよう移動範囲を調整し、コインは新しい通行可能経路から生成します。
- スコア欄の上下余白を縮めています。ジョイスティックの操作、PCのフィールドと操作、ゲームルール、BGM・効果音、保存キーは従来のままです。
